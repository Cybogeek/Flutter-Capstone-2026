# Docmind

DocMind is a Flutter application for working with documents. It is being developed as a capstone project and is currently in its early stages.

## Phase 1

Phase 1 is the initial version of the app. It establishes the project structure and includes the first basic screens and functionality needed for future development.

This version is a work in progress. There is still a lot to correct, improve, and add, including:

- Improving the user interface and user experience
- Adding and refining document features
- Improving data storage and app performance
- Adding validation, error handling, and testing
- Improving accessibility and overall stability

The current version is only a starting point and will be expanded in future phases.

## Getting Started

Make sure Flutter is installed, then run:

```bash
flutter pub get
flutter run
```

For more information, see the [Flutter documentation](https://docs.flutter.dev/).
